DailyMint

Politica de privacidad

Ultima actualizacion: 22 de junio de 2026

DailyMint es una aplicacion de microlecturas y crecimiento personal. Esta politica explica que datos se recopilan, para que se usan y como el usuario puede solicitar su eliminacion.

Datos que recopilamos

  • Datos de cuenta: correo electronico y metodo de inicio de sesion.
  • Datos de perfil interno: nombre elegido, rango etario, preferencias de lectura y objetivos seleccionados.
  • Datos de progreso: XP, nivel, racha, arbol elegido, frutos, insignias, lecturas completadas y minutos leidos.
  • Datos de contenido: valoraciones, reportes de ortografia, palabras inadecuadas, textos confusos o copyright.
  • Datos tecnicos basicos: eventos de uso y errores para mejorar estabilidad y experiencia.

DailyMint no solicita ubicacion, contactos, fotos, camara, microfono ni archivos personales del dispositivo.

Para que usamos los datos

  • Crear y mantener la cuenta del usuario.
  • Guardar el progreso de lectura entre sesiones y dispositivos.
  • Mostrar rachas, XP, arbol, frutos e insignias.
  • Mejorar el contenido mediante valoraciones y reportes.
  • Detectar errores, problemas de experiencia y comportamiento general de uso.

Servicios externos

DailyMint utiliza Firebase de Google para autenticacion, base de datos y sincronizacion del progreso. Google puede procesar datos tecnicos asociados al funcionamiento de estos servicios.

Compartir datos

No vendemos datos personales. Los datos pueden procesarse mediante proveedores tecnicos necesarios para operar la app, como Firebase o Google Cloud.

Seguridad

El progreso y los datos de usuario se guardan en Firebase. La app debe usar reglas de seguridad para que cada usuario solo pueda acceder a sus propios datos.

Eliminacion de cuenta

El usuario puede eliminar su cuenta y progreso desde la pantalla Perfil mediante la opcion "Eliminar cuenta y progreso". En algunos casos, por seguridad, Firebase puede requerir iniciar sesion nuevamente antes de eliminar definitivamente la cuenta. Tambien puede consultar las instrucciones publicas de eliminacion.

Contenido educativo

DailyMint entrega lecturas breves de caracter educativo y reflexivo. No reemplaza consejo profesional medico, financiero, legal, psicologico o religioso.

Contacto

Para consultas de privacidad, soporte o eliminacion de datos, escribir a soporte.dailymint@gmail.com.
